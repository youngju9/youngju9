
# 안녕하세요! 👋

Java와 Spring Boot를 중심으로 백엔드 개발 역량을 쌓고 있습니다.

새로운 기능을 구현하는 것뿐 아니라, 기존 기능의 문제를 발견하고 개선하는 과정에도 관심이 있습니다. 

프로젝트를 통해 사용자 편의 기능을 구현하고, 데이터 조회 방식과 화면 동작을 개선하는 경험을 쌓았습니다.

## 🛠 Tech Stack

**Backend**  
**Java · Spring Boot**   
Python · Django

**Database**  
PostgreSQL · SQL

**Mobile / Frontend**  
React Native · JavaScript  
HTML · CSS

**Tools**  
Supabase · Figma · Notion
